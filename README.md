# Text Flow
O **TextFlow** é uma ferramenta web de processamento de texto e padronização de "strings" através de conversões de caixa e remoção de acentos.

## Funcionalidades
* **Conversão de Caixa**, alterando o texto entre **maiúsculo ou minúsculo.**
* **Remove acentuações** e **converte caracteres especiais.
* **Troca `Ç` por `C`.**

## Como Usar
1. Faça o clone ou baixe este repositório.
2. Abra o arquivo `text-flow.html` diretamente em qualquer navegador de sua preferência.
