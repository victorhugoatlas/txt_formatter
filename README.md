# Text Formatter
Uma ferramenta web de processamento e padronização de texto através da conversões de caixa e remoção de acentos.

## Funcionalidades
* **Conversão de Caixa**, alterando o texto entre **maiúsculo ou minúsculo.**
* **Remove acentuações** e **converte caracteres especiais.
* **Troca `Ç` por `C`.**

## Como Usar
1. Faça o clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente em qualquer navegador de sua preferência.
